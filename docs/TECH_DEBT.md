# Technical Debt

Цей файл містить список відомих тимчасових рішень, "костилів" (hacks) та функціоналу, який потрібно доопрацювати в майбутньому.

## Frontend

### Фільтри (CatalogFilters.jsx)
- **Вкладки "Всі оголошення / Бізнес / Приватні"**: Зараз це просто візуальні заглушки. У базі даних (на бекенді) немає поділу користувачів або оголошень на "бізнес" та "приватні". Коли такий функціонал з'явиться на бекенді, потрібно додати обробку кліків по цих вкладках і передавати відповідний параметр (наприклад, `seller_type=business`) в API.
